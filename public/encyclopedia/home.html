1. What it is (one breath)

PRIME-AI is a sovereign cognitive operating environment: you give an objective; specialists are routed; they work through MCP and an event bus; a second voice challenges before anything is “done”; evidence is kept. Multi-node hardware is designed but deferred. The public face is the encyclopedia tree on yace19ai.

It is not one giant chatbot. It is Hub + domain agents (AACI) — Messages → MCP → Skills/Tools → System Prompt → Model; Tools may include nested Agents.

2. Laws (always true)

  1. Zero-Illusion — no fake done, no cosmetic confidence, no mock status lights.
  2. Second voice — no completion without Verification challenge.
  3. Capacity — max 6 awake; max 12 per mission; queue the rest.
  4. Local first — Ollama on M4 preferred.
  5. M4-only scope — sole active command node; multi-node deferred ≠ failure.
  6. Evidence — hash / artifact / proof trail before applause.

4. AACI — how minds link

AACI = Agent-to-Agent Communication Interface.

You speak
  → Hub (Command / OMNI / Command Center)
    → Route (who wakes — never everyone)
      → Bus (mission · frontier · evidence subjects)
        → Specialists (24 roles + 9 frontier accents)
          → MCP plug (tools / devices / models)
            → Verification challenges
              → Memory / evidence keeps the trail

Agent-as-tool: a parent may call another agent like a function. That is how the fleet nests without becoming one blob.
